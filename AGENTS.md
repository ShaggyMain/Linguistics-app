# SpeakStream — notes for agents

- `SPEC.md` is the source of truth (see its §15 addendum for decisions made during implementation).
- The procedural generator lives in `src/domains/atc/` and is pure TypeScript — no React Native imports there. Keep it that way: `npm test` runs it with plain ts-jest.
- App code: `src/app` (screens), `src/teleprompter` (scroll engine), `src/store` (zustand + AsyncStorage), `src/theme` (Radar Night tokens).
- New professions plug in via `src/domains/types.ts` (`Domain` interface) + one entry in `src/domains/registry.ts`. Do not touch the teleprompter for that.
- Checks: `npm test` and `npm run typecheck` must stay green. App icons are generated by `node scripts/make-icons.mjs` (dev dep `sharp`), not hand-edited.
- Hard constraints: 100% offline, free, no backend/API keys/accounts, runs in Expo Go, no LLM at runtime.
