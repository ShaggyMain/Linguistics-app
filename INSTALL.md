# SpeakStream — Android installer

**Download and open on your Android phone to install:**

➡️ https://github.com/ShaggyMain/Linguistics-app/raw/apk-download/SpeakStream-v1.0.0.apk

- Standalone build — no Expo Go and no dev server needed.

- Package `com.shaggymain.speakstream` · version 1.0.0 · arm64-v8a / armeabi-v7a / x86 / x86_64.

Signed with a debug key (fine for sideloading and testing). Source code lives on branch `claude/generative-text-reading-5a77kc`.
